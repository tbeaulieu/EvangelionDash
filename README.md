# EvangelionDash
A dashboard based upon the timer interface from Neon Genesis Evangelion. Animated with Asuka as you hit certain RPM ranges. All copyrights of Evangelion/images are owned by Studio Khara/Gainax. This file contains a font I generated called EvangelionDigital which mimics the timer better than what I could find online.
